Idempotent event processing

Deliver one event twice and inspect the resulting balance. This in-memory example illustrates the behavior of a deduplicating consumer.

const events = [
  { id: "deposit-1", amount: 70 },
  { id: "deposit-2", amount: 30 },
  { id: "deposit-1", amount: 70 },
];

const processed = new Set();
let balance = 0;

for (const event of events) {
  if (processed.has(event.id)) {
    console.log("Skipped duplicate:", event.id);
    continue;
  }

  processed.add(event.id);
  balance += event.amount;
  console.log("Applied:", event.id);
}

console.log("Final balance:", balance);

Exponential backoff

Simulate a transient dependency failure and calculate the delay before each retry. Edit the number of failures to see what happens when the retry budget runs out.

const transientFailures = 2;
const maxAttempts = 4;
const initialDelayMs = 100;
let delivered = false;

for (let attempt = 1; attempt <= maxAttempts; attempt++) {
  if (attempt > transientFailures) {
    console.log("Delivered on attempt", attempt);
    delivered = true;
    break;
  }

  console.log("Transient failure on attempt", attempt);
  if (attempt < maxAttempts) {
    const delay = initialDelayMs * 2 ** (attempt - 1);
    console.log("Scheduled retry in", delay, "ms");
  }
}

if (!delivered) console.log("Retry budget exhausted.");
